# Какой пароль использовать для Yandex SMTP?

## Варианты паролей для Yandex

Для работы SMTP с Yandex можно использовать **два типа паролей**:

### 1. Пароль приложения (рекомендуется) ⭐

**Пароль приложения** — это специальный пароль, создаваемый специально для приложений. Это более безопасный вариант.

#### Как создать пароль приложения:

1. **Включите доступ для почтовых клиентов:**
   - Войдите в аккаунт coactivity@yandex.com
   - Перейдите: https://id.yandex.ru/security
   - Найдите раздел "Пароли приложений" или "Доступ для почтовых клиентов"
   - Включите доступ для приложений

2. **Создайте пароль приложения:**
   - Откройте: https://passport.yandex.ru/profile/access
   - Нажмите "Создать пароль приложения"
   - Выберите "Почта" 
   - Укажите название (например, "CoActivity SMTP")
   - Нажмите "Создать"
   - **ВАЖНО:** Скопируйте пароль сразу — он показывается только один раз!

3. **Используйте этот пароль в `application.properties`:**
   ```properties
   spring.mail.password=ваш_пароль_приложения_здесь
   ```

### 2. Обычный пароль аккаунта

Можно использовать обычный пароль от аккаунта `coactivity@yandex.com`, **НО:**
- Может не работать, если включена двухфакторная аутентификация
- Менее безопасно
- Может блокироваться Yandex

## Текущая конфигурация

В файле `src/main/resources/application.properties` сейчас указан:

```properties
spring.mail.username=coactivity@yandex.com
spring.mail.password=Abibas1234+
```

## Какой пароль должен быть?

### Если `Abibas1234+` — это пароль от аккаунта:

✅ **Может работать**, если:
- Двухфакторная аутентификация выключена
- В настройках безопасности Yandex разрешен доступ для приложений

❌ **Не будет работать**, если:
- Включена двухфакторная аутентификация
- Yandex требует пароль приложения
- Доступ для приложений заблокирован

### Рекомендация:

**Используйте пароль приложения** — это более надежный и безопасный вариант.

## Как проверить, какой пароль работает?

1. **Запустите backend:**
   ```bash
   mvn spring-boot:run
   ```

2. **Протестируйте отправку email:**
   - Создайте тестового пользователя
   - Запросите сброс пароля
   - Проверьте логи

3. **Если видите ошибку аутентификации в логах:**
   ```
   ERROR ... EmailService - Failed to send password reset email
   javax.mail.AuthenticationFailedException: 535 5.7.8 Error: authentication failed
   ```
   
   **Это значит:** Нужно использовать пароль приложения

## Пошаговая инструкция создания пароля приложения

1. Войдите в аккаунт coactivity@yandex.com

2. Откройте настройки безопасности:
   - https://id.yandex.ru/security

3. Найдите раздел "Пароли приложений" или "Доступ для почтовых клиентов"

4. Создайте новый пароль:
   - Название: "CoActivity Backend"
   - Тип: "Почта"
   - Скопируйте сгенерированный пароль (16 символов)

5. Замените в `application.properties`:
   ```properties
   spring.mail.password=новый_пароль_приложения
   ```

6. Перезапустите backend

## Альтернативный способ (если пароль приложения недоступен)

Если нет возможности создать пароль приложения:

1. Проверьте настройки безопасности: https://id.yandex.ru/security
2. Убедитесь, что доступ для приложений разрешен
3. Если включена 2FA, временно отключите её (не рекомендуется)
4. Используйте обычный пароль от аккаунта

## Итог

**Для надежной работы используйте:**
- ✅ Пароль приложения (рекомендуется)
- Или обычный пароль, если 2FA отключена и доступ разрешен

**Текущий пароль `Abibas1234+`:**
- Если это пароль приложения → всё правильно
- Если это обычный пароль → может не работать, лучше создать пароль приложения

## Проверка работы

После настройки проверьте логи при отправке email:
- ✅ Успех: `INFO ... EmailService - Password reset email sent to: ...`
- ❌ Ошибка: `ERROR ... AuthenticationFailedException` → нужен пароль приложения
