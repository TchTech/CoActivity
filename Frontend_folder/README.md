# CoActivity - Приложение для совместных активностей

Социальная сеть для создания комнат по интересам, где люди могут находить единомышленников и организовывать совместные мероприятия.

## Особенности приложения

### Социальная сеть
- **Посты с интеграцией комнат** - публикация контента с привязкой к мероприятиям
- **Лайки, комментарии, просмотры** - полноценное взаимодействие с контентом
- **Подписки и лента** - персонализированный контент от интересных авторов
- **Уведомления (колокольчик)** - информирование о важных событиях

### Система комнат
- **Открытые комнаты** - вход в один клик для быстрого присоединения
- **Комнаты по заявкам** - модерируемый отбор участников
- **Групповой чат** - общение участников с возможностью отправки файлов
- **Организация мероприятий** - онлайн и оффлайн форматы

### Репутация и верификация
- **Система отзывов** - участники оценивают мероприятия и менторов (0-5 звезд)
- **Видимые бейджи** - у менторов и проверенных авторов
- **Верификация по email** - подтверждение учетной записи

### Профиль пользователя
- **Ссылки на внешние ресурсы** - Github, личный сайт и другие
- **Увлечения и интересы** - теги для поиска единомышленников
- **Рейтинг** - отображение средней оценки от участников мероприятий

## Дизайн

Приложение выполнено в стиле **FAANG** с использованием:
- **Цветовая схема**: Графит (#121212) + Золото (#D4AF37)
- **Шрифт**: Roboto (Google Fonts)
- **UI/UX**: Минималистичный, чистый, профессиональный дизайн
- **Адаптивность**: Оптимизация для мобильных устройств, планшетов и десктопов

## Технологии

- **React** - библиотека для построения UI
- **Next.js** - фреймворк для React приложений
- **CSS3** - стилизация с использованием CSS переменных
- **JavaScript (ES6+)** - современный синтаксис

## Навигация

Приложение включает следующие страницы:

1. **Вход/Регистрация** - аутентификация пользователей
2. **Профиль** - личная страница с постами и информацией
3. **Комментарии** - просмотр поста с комментариями и ответами
4. **Мои комнаты** - список активных комнат в стиле мессенджера
5. **Чат комнаты** - групповое общение участников
6. **Информация о комнате** - детали мероприятия
7. **Создание поста** - публикация контента
8. **Создание комнаты** - организация мероприятия

## Функциональные требования

Реализованы в соответствии с ФТ:
- Регистрация и вход (email/никнейм + пароль ≥8 символов)
- Публикация постов (1-1000 символов, изображение до 10 МБ)
- Лайки и комментарии (до 500 символов)
- Подписки на пользователей
- Создание комнат (открытые/по заявкам, онлайн/оффлайн)
- Поиск и фильтрация комнат
- Групповой чат (до 500 символов, файлы до 10 МБ)
- Система уведомлений
- Профили с рейтингом и отзывами
