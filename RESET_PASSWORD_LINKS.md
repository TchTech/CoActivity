# Рабочие ссылки сброса пароля

## Обзор

Система сброса пароля полностью настроена. Ссылки из email открывают страницу, похожую на страницу регистрации, где пользователь может ввести новый пароль.

## Как это работает

### 1. Запрос сброса пароля

Пользователь переходит на страницу "Забыли пароль?" и вводит email:
- Frontend: `http://localhost:3000` → нажимает "Забыли пароль?"
- Форма отправляет запрос на: `POST /password-reset/request` с email

### 2. Отправка письма

Backend отправляет письмо на указанный email со ссылкой:
```
http://localhost:3000/reset-password?token=UUID-токен
```

### 3. Переход по ссылке

Когда пользователь переходит по ссылке из письма:

1. **Открывается Next.js страница**: `/reset-password?token=...`
2. **Токен извлекается из URL** автоматически
3. **Проверяется валидность токена** через API
4. **Отображается форма** для ввода нового пароля (похожа на регистрацию)

### 4. Установка нового пароля

Пользователь вводит новый пароль дважды (для подтверждения) и нажимает "Сохранить новый пароль":
- Форма отправляет: `POST /password-reset/confirm` с токеном и новым паролем
- Пароль хешируется и сохраняется
- Показывается сообщение об успехе

## Структура файлов

### Backend
- `PasswordResetToken` - модель токена
- `PasswordResetService` - логика сброса пароля
- `EmailService` - отправка писем через SMTP
- `PasswordResetController` - REST API endpoints

### Frontend
- `frontend/app/reset-password/page.tsx` - Next.js страница для обработки URL
- `frontend/hypertexts/ResetPassword.jsx` - компонент формы сброса пароля
- `frontend/hypertexts/ForgotPassword.jsx` - страница запроса сброса

## URL структура

### Ссылка в письме
```
http://localhost:3000/reset-password?token=UUID-токен
```

### Next.js роутинг
- URL: `/reset-password?token=...` → открывает `frontend/app/reset-password/page.tsx`
- Компонент автоматически извлекает токен из URL параметров
- Показывает форму для ввода нового пароля

## UI

Страница сброса пароля выглядит так же, как страница регистрации:
- Та же структура (auth-container, auth-card, auth-logo)
- Те же стили (input-group, input-label, input)
- Два поля для пароля (новый пароль + подтверждение)
- Кнопка "Сохранить новый пароль"
- Ссылка "Вернуться ко входу"

## Тестирование

### 1. Запустите backend и frontend:
```bash
# Backend
mvn spring-boot:run

# Frontend (в другом терминале)
cd frontend && pnpm dev
```

### 2. Запросите сброс пароля:
1. Откройте `http://localhost:3000`
2. Нажмите "Забыли пароль?"
3. Введите email зарегистрированного пользователя
4. Нажмите "Отправить инструкции"

### 3. Проверьте почту:
- Откройте почтовый ящик (или MailHog, если используете)
- Найдите письмо от coactivity@yandex.com
- Скопируйте ссылку из письма

### 4. Перейдите по ссылке:
- Откройте ссылку в браузере
- Должна открыться страница `/reset-password?token=...`
- Форма для ввода нового пароля должна быть видна
- Введите новый пароль и подтвердите его
- Нажмите "Сохранить новый пароль"

### 5. Проверьте результат:
- Должно появиться сообщение "Пароль успешно изменен"
- Перейдите на страницу входа
- Войдите с новым паролем

## Проверка ссылок

```
http://localhost:3000/reset-password?token=123e4567-e89b-12d3-a456-426614174000
```

При переходе по ссылке:

- ✅ Токен автоматически извлекается из URL
- ✅ Проверяется валидность токена
- ✅ Пользователь может ввести новый пароль
- ✅ После сохранения показывается успешное сообщение

## Настройка URL

В `application.properties` можно изменить базовый URL:

```properties
app.password-reset.base-url=http://localhost:3000
```

Для продакшена:
```properties
app.password-reset.base-url=https://yourdomain.com
```
